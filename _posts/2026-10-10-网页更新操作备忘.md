#### Git 安装配置

* Windows 下，通常安装 [Git for Windows](https://git-scm.com/install/windows)。
* Git for Windows 里有 git-bash，这是 git 的一个实现软件。这个是 cmd 界面。
* 如果喜好 gui 界面，它也有 git-gui 可用。
* 安装之后，在任何文件夹里，右击鼠标，出来的菜单里会有 git-bash 执行入口。
* 执行 git-bash，输入 git 命令，做需要的操作。它会把当前文件夹当作工作文件夹。

#### Git 常用操作

* 将本地仓库的变更上传到远程仓库。注意，所有变更要先提交到本地仓库。

  ```  git push    ```
    
* 如果某些文件有修改，需要将修改提交到本地仓库。并附上说明。
  
  ```  git commit --all  -m "this is change"    ```
  
* 如果添加了一个文件，要让 git 知晓。之后也要将这个添加提交到本地仓库。

  ```  git add newfile.md    ```  
    
* 如果要删去一个文件，则执行 git rm。注意，不能在本地文件夹中直接删去。

    ```  git rm xxfile.md    ```      
    
* 首次将远程网站文件下拖到本地，成立本地仓库
    
   ``` git clone   ```
   
   
#### Clash Verge 基本道理

* 建立一个中间代理，我的网络访问要求，先发送到这个代理网站，它转发到我的目的网站；
* 我的目的网站的回应，发到代理网站。代理网站会转发到我这边。
* 代理网站都是些商业网站，有些是免费的。它的工作就是转发。转发的内容可能是加密的。
* Clash Verge 汇集了很多代理网站，你可以选择一个来用。
