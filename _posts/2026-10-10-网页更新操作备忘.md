#### Git 常用操作

* 将本地仓库的变更上传到远程仓库。注意，所有变更要先更新到本地仓库。

  ```  git push    ```
    
* 如果某些文件有修改，需要确认将修改更新到本地仓库。并附上说明。
  
  ```  git commit --all  -m "this is change"    ```
    
* 首次将远程网站文件下拖到本地，成立本地仓库
    
   ``` git clone     ```
   
   
#### Clash Verge 基本道理

* 建立一个中间代理，我的网络访问要求，先发送到这个代理网站，它转发到我的目的网站；
* 我的目的网站的回应，发到代理网站。它转发到我这边。
* 代理网站都是些商业网站，有些是免费的。它的工作就是转发。转发的内容可能是加密的。
