    古人的名字，名是名，字是字。一般来说，出生时或上学始由父祖取名，十四五岁成年时取字。字可能是自己
    本人取，也可能请有学问的旁人取。称呼别人，要称字，不称名。直呼其名是冒犯对方。只有自己的
    家人可以呼名。近人如毛泽东，泽东是名。他字润之。看电视剧里，别人称呼他润之。朱德，德是名。他字玉阶。别人呼他玉阶兄。

#### Git 常用操作

* 将本地仓库的变更上传到远程仓库。注意，所有变更要先提交到本地仓库。

  ```  git push    ```
    
* 如果某些文件有修改，或添删了文件，需要将修改提交到本地仓库。并附上说明。
  
  ```  git commit --all  -m "this is change"    ```
  
* 如果添加了一个文件，要让 git 知晓。之后也要将这个添加提交到本地仓库。

  ```  git add newfile.md    ```  
    
* 如果要删去一个文件，则执行 git rm。注意，不能在本地文件夹中直接删去。

    ```  git rm xxfile.md    ```      
    
* 如果要更改某个文件名，则执行 git mv。

    ```  git mv cmake cmake.md    ```         
    
* 首次将远程网站文件下拖到本地，成立本地仓库。
    
   ``` git clone  git://github.com/yucailee/yucailee.github.io.git  ```
   
* 创建本地仓库

    ``` git init  ```   

* 本地仓库创建了，就可以如上添加文件，并提交到本地仓库。

* 也可以指定仓库的分支名，github 上默认的分支名现在是 main：

    ``` git branch -M main  ```          
   
* 将本地仓库与网上仓库关联起来。前提是网上仓库已经创建，但还是空的。
   
   ``` git remote add origin https://github.com/yucailee/newrepo.git       ```  
   
* 然后**首次**将本地仓库远程更新到网上仓库。

   ``` git push -u origin main        ```     
   
* 在 github 上创建仓库，一般是登录 github 网站里手动创建。
   据说 gitHub 也提供有 gh 工具，可用来在本地创建 github 仓库。
   

    
    
#### 基本道理

* 建立一个中间代理，我的网络访问要求，先发送到这个代理网站，它转发到我的目的网站；
* 我的目的网站的回应，发到代理网站。代理网站会转发到我这边。
* 代理网站都是些商业网站，有些是免费的。它的工作就是转发。转发的内容可能是加密的。
* Clash Verge 汇集了很多代理网站，你可以选择一个来用。
